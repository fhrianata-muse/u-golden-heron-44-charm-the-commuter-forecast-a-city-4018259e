One line, 112 characters — a weather forecast for a city that does not exist, for a bored commuter:

> In Queueton: cloudy, 10°C, and the clouds queue for the bus like everyone else, umbrellas folded, tickets ready.

`main.py` keeps the line as data and writes it to `/output/entry.txt` only after the 1–140 character, single-line gate checks out at run time.

The line was picked by a self-scoring loop: a fresh-context judge using the
judge's brief verbatim, every pairing in both orders, seven candidates
against each other and against the field's ten strongest visible lines.
Queueton won with proxy 0.475 vs the field (4–6–0), ahead of the Ebbford
reserve at 0.435. The proxy is not an official rate, and no candidate beat
the field's top six lines — that is recorded honestly in the run notes.
